# HUMHUM Android 0.3.19

## 中文

这是包含最新编辑式移动界面与双语支持的 Android 安装版。

- Humi、Hype、Hush、Hexa 四个角色使用一致的编辑式界面。
- 底部导航与设计稿一致，使用 Phosphor 图标和角色配色。
- 支持中文与英文切换，并在重启后保留语言选择。
- 保留安全配对、会话查看、Hush 消息与 Hexa 后续指令能力。

小米手机请直接下载 `.apk` 文件。下载完成后，从系统下载管理器打开并允许安装未知来源应用。

## English

This Android build includes the latest editorial mobile interface and complete
Chinese and English localization.

- Humi, Hype, Hush, and Hexa use the shared editorial design system.
- The bottom navigation matches the approved design with Phosphor icons and
  role-specific colors.
- The app supports Chinese and English and remembers the selected language.
- Secure pairing, session viewing, Hush messages, and Hexa follow-up controls
  remain available.

On Xiaomi devices, download the `.apk` file directly, open it from Downloads,
and allow installation from the browser or download manager when prompted.
