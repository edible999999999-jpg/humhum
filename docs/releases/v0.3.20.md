# HUMHUM 0.3.20

## Remote Hexa control

- Keeps the most recently successful Relay route active for session refresh, conversation viewing, approvals, Hush refresh and follow-up messages.
- Prevents a timed-out encrypted remote write from being sent again to a stale LAN address.
- Persists phone follow-ups on the Mac before acknowledging them, then delivers long-running Agent work in the background.
- Returns a truthful queued state while Claude, Codex, OpenCode or Qoder continues locally.

## Release pairing

Install 0.3.20 on both macOS and Android. Existing control-scope pairings with Anywhere v2 credentials remain compatible; re-pair only if the phone no longer has a usable encrypted Relay configuration.
