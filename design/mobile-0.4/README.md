# HUMHUM Android 0.4 UI

This directory is the visual source of truth for the Android companion redesign.

## Design artifacts

- [Figma design system](https://www.figma.com/design/YHi0NWZs5j2PhjjQgLU0aR)
- `index.html`: six-screen high-fidelity design board at 390 x 844
- `design-board.png`: frozen review image of the complete design board
- `screenshots/`: Android 16 emulator captures produced by Compose instrumentation

The Figma file contains HUMHUM color, typography, spacing, radius, and elevation
tokens. Figma screen insertion is currently blocked by the connected account's
View seat; the runnable board and device captures preserve the approved layout
until edit access is restored.

## Product rules

- The first viewport leads with the user's work, not mascot art or raw metrics.
- Humi prioritizes today's focus and observed health summaries.
- Hype presents reusable knowledge instead of files and scan counts.
- Hush is a private inbox with people, previews, source, time, and clear privacy
  boundaries.
- Hexa keeps the current Agent task and follow-up composer visible together.
- Pairing leads with QR scanning; manual credentials stay behind recovery.
- Role identity comes from color, iconography, language, and task structure.
